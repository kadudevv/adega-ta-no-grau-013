# Adega Tá no Grau 013

Site institucional da Adega Tá no Grau 013 — Praia Grande/SP.

## Código-fonte

Este repositório receberá a versão React + Vite + TypeScript do site original, incluindo a vitrine com quatro fotos reais: cervejas, refrigerantes e energéticos, tabacaria e gelo.

## Publicação no Render

Este projeto deve ser configurado como **Static Site** com:

- Branch: `main`
- Build Command: `npm ci && npm run build`
- Publish Directory: `dist`
- Auto Deploy: `On Commit`

O pacote do projeto inclui `render.yaml` com a configuração de implantação.

**Situação:** aguardando envio dos arquivos do projeto e a criação do serviço no Render. O site ainda não está publicado por este repositório.

## Desenvolvimento local

```bash
npm ci
npm run dev
```

Confirme os números e links de atendimento, dados de avaliações, política de privacidade e horários antes de divulgar o site.
